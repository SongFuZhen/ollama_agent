SimpUI 组件预览

Buttons

使用方式：

<button class="simpui-btn primary sm">Primary</button> <button class="simpui-btn secondary sm">Secondary</button> <button class="simpui-btn success sm">Success</button> <button class="simpui-btn primary">Normal</button> <button class="simpui-btn primary md">Medium</button> <button class="simpui-btn primary lg">Large</button>

Badge

Primary Success Warning Danger

使用方式：

<span class="simpui-badge primary">Primary</span> <span class="simpui-badge success">Success</span> <span class="simpui-badge warning">Warning</span> <span class="simpui-badge danger">Danger</span>

Input

使用方式：

<input type="text" class="simpui-input" placeholder="Default input"> <input type="text" class="simpui-input primary" placeholder="Primary input"> <input type="text" class="simpui-input success" placeholder="Success input"> <input type="text" class="simpui-input danger" placeholder="Danger input">

Textarea

使用方式：

<textarea class="simpui-textarea" rows="3" placeholder="Enter text..."></textarea>

Checkbox & Radio

使用方式：

<label class="simpui-checkbox"> <input type="checkbox"> Option 1 </label> <label class="simpui-radio"> <input type="radio" name="demo"> Radio 1 </label>

Select

使用方式：

<select class="simpui-select"> <option value="">Choose an option</option> <option value="1">Option 1</option> <option value="2">Option 2</option> </select>

Modal

使用方式：

<button class="simpui-btn primary" onclick="document.getElementById('modal').style.display='flex'">Open Modal</button> <div id="modal" class="simpui-modal" style="display: none;"> <div class="simpui-modal-content"> <div class="simpui-modal-header"> <h3>Modal Title</h3> <span class="simpui-modal-close" onclick="document.getElementById('modal').style.display='none'">&times;</span> </div> <div class="simpui-modal-body"> <p>Modal content here.</p> </div> <div class="simpui-modal-footer"> <button class="simpui-btn light" onclick="document.getElementById('modal').style.display='none'">Cancel</button> <button class="simpui-btn primary" onclick="document.getElementById('modal').style.display='none'">Confirm</button> </div> </div> </div>

Toast

使用方式：

<button class="simpui-btn success" onclick="simpuiToast('Success!', 'success')">Success Toast</button> <script> function simpuiToast(message, type) { const toast = document.createElement('div'); toast.className = `simpui-toast ${type}`; toast.textContent = message; document.body.appendChild(toast); setTimeout(() => toast.remove(), 3000); } </script>

Dark Mode

使用方式：

<button class="simpui-btn dark" onclick="document.body.classList.toggle('dark-mode')">Toggle Dark Mode</button>
