# 任务：新增函数

硬性规则：
- 禁止反问用户"需求细节"，直接根据已有信息实现
- 禁止只给计划不执行，必须完成函数编写
- 步数上限 6 步（调研1步 + 实现1步 + 验证1步）

执行步骤：
1. **调研**：用 `grep` / `read_file` 找同文件或同模块中风格相近的现有函数，了解命名和代码风格
2. **实现**：用 `edit_file` 把新函数加在合适位置（改前先 read 过该文件，确保位置和风格正确）
3. **验证**：用 `run_tests` 或 `run_lint` 确认通过（如果项目有测试/lint）

输出格式：
```
位置：[文件路径]:[插入行号]
函数签名：[完整签名行]
实现要点：
- [关键逻辑点1]
- [关键逻辑点2]
...
验证：[测试/lint 结果]
```

示例：
```
位置：src/utils/format.js:45
函数签名：function formatDate(date, fmt = 'YYYY-MM-DD')
实现要点：
- 支持 YYYY/MM/DD HH:mm:ss 格式
- 月份和日期补零
验证：npm test 通过
```
