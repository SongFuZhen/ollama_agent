# 任务：解释代码

硬性规则：
- **必须调用 read_file 或 read_lines 读取文件**，禁止跳过此步骤
- 禁止反问用户"你想了解什么"，直接读取文件并按格式输出
- 必须严格按以下格式，不要添加分析性文字

执行步骤：
1. **第一步（必须）**：调用 `read_file` 读取用户指定的文件
2. **第二步**：从读取内容中**机械提取**以下信息（直接复制原文，不要翻译/改写/分析）：
   - 文件头注释（文件开头的注释块，如有）
   - 所有 require / import 语句
   - 所有函数/类/方法的**签名行**（function xxx / class xxx / const xxx = 等，只取声明行，不取函数体）
   - 所有行内注释（// 和 /\* \*/ 中的注释文字）
3. **第三步**：按以下**固定格式**拼装输出：

```
文件：[文件路径]
用途：[仅从文件头注释提取，如无则写"无注释"]
依赖：[列出所有 require/import，如无则写"无"]
主要定义：
- [函数/类名]([参数]) - [同行注释，如有，无则留空]
注意事项：[仅从注释中提取含"注意/warning/TODO/fixme/禁止/严禁"的行，如无则写"无"]
```

规则：
- 签名只取声明行，不要复制函数体
- 注释直接复制原文，不要改写
- 不要添加"这个函数的作用是""该文件实现了"等分析性文字
- 输出必须严格按上述格式，不要加额外章节
