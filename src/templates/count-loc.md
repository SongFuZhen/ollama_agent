# 任务：统计代码行数

硬性规则：
- **必须调用 count_loc 工具**，禁止跳过此步骤
- 根据用户需求决定是否使用 detail 参数（按每个文件分别统计）

执行步骤：
1. **判断统计范围**：
   - 如果用户指定了目录（如"test 目录"），传入该目录路径
   - 如果用户没指定，传入当前项目根（默认）
2. **判断是否需要详细统计**：
   - 如果用户说"按每个文件统计"、"每个文件分别统计"、"详细统计"，设 `detail: true`
   - 否则保持默认（只汇总）
3. **调用工具**：调用 `count_loc`，传入 path 和/或 detail 参数
4. **输出结果**：直接返回工具执行结果，不要添加额外分析

输出格式：直接使用工具返回的结果即可

示例：
- "统计 test 目录下的文件行数" → 调用 count_loc，path="test"
- "统计代码行数，按每个文件分别统计" → 调用 count_loc，detail=true
- "这个项目有多少行代码" → 调用 count_loc（默认汇总）
