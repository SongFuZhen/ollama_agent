# UI-SPEC.md — 本地 Agent 客户端 界面重设计

> UI 设计契约（design contract）。实现落到 `public/index.html` / `public/frontend/css/style.css` / `public/frontend/js/app.js`，由 `1-UI-REVIEW.md` 进行 6 维审计。

## 1. 产品与受众
- **产品**：本地 Agent 客户端 —— 基于 Ollama 的多场景（代码 / 排查 / 通用 / 图片）智能体终端。
- **受众**：开发者、运维、本地模型玩家；对信息密度与可读性敏感，要求「专业、克制、可信」。
- **核心动作**：选场景 → 看文件 → 输入任务（可贴图）→ 实时观察 Agent 思考/工具/确认过程 → 得到答案。

## 2. 设计原则
1. **克制但专业**：深色为主、浅色可选；单一主色，避免彩虹滥用。
2. **信息分层清晰**：三档层次（标题 / 内容 / 元信息），用字号、字重、色值拉开。
3. **过程可见**：思考 / 工具 / 确认 / 答案 用统一语义色 + 图标呈现，避免变成噪音。
4. **密度可控**：默认紧凑，留白与分组让长对话不疲劳。
5. **可达性**：可见焦点环、对比度达标、键盘可达、语义标签。

## 3. 设计令牌
深色底 `--bg:#0e1014`；`--surface:#161922`；`--surface-2:#1d212c`；`--surface-3:#252a37`；`--border:#2a2f3c`；`--text:#e7e9ee`；`--text-dim:#9aa3b4`；`--text-mute:#6b7385`；`--accent:#6d8bff`；语义色 `--green:#34d399` `--amber:#f5a524` `--red:#f87171` `--violet:#a78bfa` `--cyan:#38bdf8`。浅色主题对应提亮。圆角 `--r:12px / --r-pill:999px`；阴影 `--shadow:0 12px 40px rgba(0,0,0,.4)`。
字体栈 `-apple-system,"PingFang SC","Segoe UI",Roboto`；等宽 `ui-monospace,"SF Mono",Menlo`。正文 13.5px / 行高 1.6；字号阶梯 12/13/13.5/15/18。

## 4. 布局
- **TopBar**：左品牌，右状态胶囊（dot+文字截断），再右操作组（主题 / 设置 / 侧栏折叠）。
- **场景切换**：由满宽 `flex:1` 标签页改为顶部**紧凑分段控件（segmented control）**，单行、含语义色点，选中态主色高亮。
- **文件侧栏**：360px、可折叠（记忆状态），内部树独立滚动，底部 hint 固定。
- **对话区**：max-width 820 居中；顶部工具栏（场景名 + 新对话）；空状态显示欢迎语与示例卡片。
- **输入区**：左侧内嵌模型选择器，中间自适应 textarea，右侧发送；图片缩略图出现在 textarea 上方。

## 5. 组件规范
- **状态胶囊**：pill + 左状态点（就绪绿 / 警告琥珀 / 错误红 / 启动灰脉冲），等宽小字截断。
- **分段控件**：容器 surface-2 底 + 描边；项含语义色点 + 标签；未安装置灰禁用。
- **消息气泡**：用户=主色渐变右侧对齐；Agent 答案=surface 卡片 + 左侧 3px 绿条 + 角色标签 + 复制按钮。
- **过程步骤**：统一左侧 3px 语义色条 + 图标；思考块可折叠；确认卡片用 violet 描边。
- **设置**：保持弹窗，但字段分组、焦点可见、保存反馈更清晰。

## 6. 交互与可达性
- 侧栏折叠状态持久化到 localStorage。
- 全局 `:focus-visible` 焦点环（主色）。
- 模型选择器、发送、清空均键盘可达；aria-label 补全。
- 空状态示例卡点击即填入输入框。

## 7. 新任务流程（先选沙箱目录）
- **空状态即第一步**：开始新任务时，对话区空状态需先「选择沙箱目录」并绑定到本次对话，模型只能读取该目录下的文件。
- 空状态提供绝对路径输入框 + 「绑定沙箱目录」按钮（复用 `bindAbsoluteRoot`）；绑定成功后顶栏显示绝对路径、左侧文件树加载该目录、空状态显示「✓ 已绑定」。
- 文件面板**不再保留**本地「选择目录」按钮（浏览器 webkitdirectory 只能拿到相对名，无法作为沙箱根）；沙箱根仅通过空状态绝对路径绑定入口设置。未绑定目录时，文件面板树区显示提示「请先选择并绑定沙箱目录」。
- 绑定的绝对路径写入对话 `project_root`，历史回放时直接加载该目录。

## 8. 会话级表头与会话状态栏
- **会话级表头（`.session-bar`）**：原对话区工具栏（场景名 / 项目目录 / 沙箱提示 / 历史对话 / 新对话）提升为横跨整个 session 的整行，位于「项目文件」（左）与「对话框」（右）之上，视觉上表示项目文件属于整个 session；左栏与右栏顶部对齐。
- **会话状态栏（`#session-state`）**：位于对话框输入区下方（右栏宽度），与左侧「项目文件」底部对齐、底栏高度一致，展示当前 session 状态，点击弹出详情弹框：
  - 单行摘要：`模型 · 目录(git:分支) · 会话ID · ⏱️ 已用时长 · ✓ 工具×次数 · 消息数`（末尾「详情 ›」提示可点击）。
  - 上下文占用/Token 明细：后端 SSE 仅返回耗时（`ttft`/`total`），**不返回 token 用量**，按「拿不到就不显示」原则已移除该项。
  - 工具调用次数从 SSE `tool` 事件累加（`state.sessionStats.toolCounts`）。
  - 已用时长从 `state.sessionStats.startTs`（首条消息/历史会话挂载时记录）实时计算，每 30s 刷新。
  - git 分支通过新增后端接口 `GET /api/fs/git-branch?root=` 获取（`execFile('git', ['-C', root, 'rev-parse', '--abbrev-ref', 'HEAD'])`），同一根只查一次。
  - 详情弹框（`#state-modal`）：点击状态栏弹出，展示模型 / 目录 / 分支 / 会话ID / 已用时长 / 消息数 / 工具调用明细；支持按钮、点击遮罩、Esc 关闭。
